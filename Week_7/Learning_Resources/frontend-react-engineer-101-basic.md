# Frontend React Engineer [101-BASIC]

## Topics Covered

- Introduction to Frontend Development
- Introduction to React
- React Features
- React Application Structure
- JSX
- Components
- Functional Components
- Props
- State
- Event Handling
- Conditional Rendering
- Rendering Lists
- Keys in React
- React Hooks
- useState
- useEffect
- Forms and Form Handling
- API Integration
- React Router
- Component Reusability
- Debugging React Applications

## Key Learnings

- Understood the role of frontend development in creating interactive web applications.
- Learned the basic concepts and features of the React library.
- Understood how JSX is used to write HTML-like structures inside JavaScript.
- Learned how React applications are built using reusable components.
- Understood the difference between Props and State and how they are used to manage data.
- Learned how to handle user events and dynamically update the user interface.
- Understood conditional rendering and rendering lists in React.
- Learned the purpose of React Hooks such as useState and useEffect.
- Gained an understanding of handling forms and integrating APIs into React applications.
- Learned the basics of routing and organizing React applications.

## Outcome

Gained foundational knowledge of React and understood how to develop reusable, interactive, and component-based frontend applications.
